# AIMock — Design Reference

Здесь хранятся **утверждённые статические дизайн-макеты** AIMock, на которые можно опираться при последующей разработке продукта. Это не фронтенд приложения: **нет JavaScript, API, реальных действий, навигационной логики или бэкенда**.

## Актуальный дизайн

**Тёмная минималистичная тема в духе ChatGPT, но со своей идентичностью AIMock.**

- [«Обзор» — открыть HTML](./index.html) — **утверждён, 26.10.2026**.
- [Стили «Обзора»](./styles/overview-dark.css).
- [Правила визуальной системы](./docs/DESIGN_RULES.md).

Откройте `index.html` в браузере. Запуск сборки или сервера не требуется. Экран содержит только вымышленные демонстрационные данные.

### Структура

```text
index.html                         Главный эталон: Обзор (Dark)
styles/
  overview-dark.css                Стили актуального экрана
  overview-light.css               Стили архивного светлого варианта
archive/
  overview-light/
    index.html                     Историческая светлая версия
docs/
  DESIGN_RULES.md                  Зафиксированные дизайн-решения
```

### Статусы страниц

| Страница | Статус |
| --- | --- |
| Обзор организации | **Утверждён — текущий Dark Minimal** |
| Диалоги | Требует нового статического экранного эталона |
| Агенты: список | Не утверждён в новом стиле |
| Детальная страница агента | Не утверждена в новом стиле |
| Workspace | Не утверждён |
| Команда (только организация-компания) | Не утверждена |
| Интеграции, Аналитика, Финансы и остальные | Не утверждены |

Ранее согласованные изображения могут служить вдохновением, но не считаются текущим дизайн-эталоном после перехода на новую тёмную тему.

### Правила изменений

Работаем **страница за страницей**, обновляем только согласованные элементы. Новый дизайн фиксируется в репозитории после просмотра и явного подтверждения. Стараемся придерживаться KISS/DRY, избегать дублирования общих компонентов и сложных декоративных конструкций.

**Важно:** этот репозиторий — источник визуальных решений. Актуальная продуктовая спецификация AIMock остаётся источником истины для функций, тарифов, интеграций и бизнес-правил.
