# AIMock — Design Reference

Здесь хранятся **утверждённые статические дизайн-макеты** AIMock, на которые можно опираться при последующей разработке продукта. Это не фронтенд приложения: **есть только демонстрационный JavaScript для просмотра интерфейса; нет API, реальных операций, данных пользователей или бэкенда**.

## Актуальный дизайн

**Тёмная минималистичная тема в духе ChatGPT, но со своей идентичностью AIMock.**

- [«Обзор» — открыть HTML](./index.html) — **утверждён, 26.10.2026**.
- [Базовые стили](./styles/overview-dark.css), [сетка и отступы](./styles/layout.css).
- [Демо-взаимодействия](./scripts/overview.js) — открытие меню и предпросмотров без выполнения реальных действий.
- [Правила визуальной системы](./docs/DESIGN_RULES.md).

Откройте `index.html` в браузере. Запуск сборки или сервера не требуется. Экран содержит только вымышленные демонстрационные данные. Доступны сворачивание меню, попап пространства и аккаунта, макетный поиск, предпросмотры списков и уведомлений. Нажатия на неразработанные разделы открывают честный экран-заглушку. Период меняет только подпись, показатели не пересчитываются.

### Правила изменений

Работаем **страница за страницей**, обновляем только согласованные элементы. Новый дизайн фиксируется в репозитории после просмотра и явного подтверждения. Стараемся придерживаться KISS/DRY, избегать дублирования общих компонентов и сложных декоративных конструкций.

**Важно:** этот репозиторий — источник визуальных решений. Актуальная продуктовая спецификация AIMock остаётся источником истины для функций, тарифов, интеграций и бизнес-правил.

- **Настройки агента v6 (на согласовании):** предметная задача, HR-вакансии и ответственный, уведомления, выбор модели, доступы/теги, ссылки на знания и интеграции. Глобальные профессиональные правила не редактируются.

- **Sharing & Copying v1.0 (визуальная проработка, не публикация):** верхние действия «Поделиться» и «Перенести», выбор материалов, предупреждение о повторном подключении, безопасный предпросмотр read-only карточки, серверные проверки прав/квот перед реальным копированием. Никаких настоящих share-токенов и экспортов в этом репозитории.

- **Редизайн детали агента:** компактный профиль, тёмно-фиолетовая локальная тема, обзор с показателями/задачей/событиями/динамикой; готовность к запуску перенесена в настройки, внутри настроек есть боковая навигация. Всё в ветке PR #14 до проверки.

- **Настройки готовой профессии (UI на согласовании):** HR/работодатель, вакансии, ответственный, необязательные пожелания; никаких обязательных универсальных промптов. [Открыть редактируемый черновик HR](./pages/agent-detail.html?agent=a8&tab=settings). Пример профиля работодателя и список загруженных материалов сохраняются только в браузере — это не API и не реальная загрузка.

## Деталка агента: карточки-разделы (редизайн 27.10.2026)

- `pages/agent-detail.html?agent=a1` — стартовый экран HR: **шесть кликабельных карточек**, без горизонтального меню: Настройки, Вакансии, Кандидаты, База знаний, Интеграции, Журнал. Тестирование доступно также из быстрых действий.
- При выборе карточки браузер **переходит по отдельному URL** `?agent=a1&tab=settings` и показывает полноэкранный **раздел** без профиля агента, без верхней панели вкладок и без обзорных карточек. «Вернуться к агенту» и крошки ведут назад. Все внутренние ссылки работают по тем же маршрутам; отдельный backend router не требуется для статического прототипа.
- `?agent=a1&tab=vacancies` — визуальный список вакансий; редактор вакансий потребует отдельной реализации. Для не-HR агента вместо «Вакансии» и «Кандидаты» показываются «Заявки» и «Тестирование», без доступа к HR-вакансиям.
- «Динамика работы» удалена из HTML и JS обзора. Остались четыре метрики (демоданные), «Последние события», «Основная задача», «Быстрые действия».
- Локальная палитра агентских экранов приближена к утверждённым «Обзору» и «Агентам» — графитовые поверхности, серые границы, приглушённый зелёный акцент. Глобальные страницы и каталог не изменялись.

Для оценки редактируемой версии: `pages/agent-detail.html?agent=a8&tab=settings`. Работающий агент доступен только для просмотра; остановка выполняется из начального экрана агента.

- **Настройки агента v2 (гибрид дизайнов №1 и №4):** сгруппированная боковая навигация, центральные формы и справа динамические подсказки по выбранному разделу. Проверка: [HR-агент](./pages/agent-detail.html?agent=a1&tab=settings), [редактируемый черновик](./pages/agent-detail.html?agent=a8&tab=settings), [менеджер заявок](./pages/agent-detail.html?agent=a2&tab=settings). Демонстрационные состояния и локальное автосохранение, без реального AI/API.
