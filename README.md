# AIMock — Design Reference

Здесь хранятся **утверждённые статические дизайн-макеты** AIMock, на которые можно опираться при последующей разработке продукта. Это не фронтенд приложения: **есть только демонстрационный JavaScript для просмотра интерфейса; нет API, реальных операций, данных пользователей или бэкенда**.

## Подбор персонала — UX-прототип (29.10.2026, draft PR #22)

**Навигация:** направление «Подбор персонала» появляется в Workspace с HR-данными или включённым HR-направлением; в демонстрационной компании оно видно, в пустом личном Workspace скрыто. В раскрывающемся разделе два пункта: «Вакансии» и «Кандидаты». Это не постоянные пункты основной навигации для всех пользователей.

**Рабочие страницы:**
- [Вакансии](./pages/vacancies.html) — каталог, поиск, фильтрация по статусу и счётчики;
- [Редактор вакансии](./pages/vacancy-detail.html) — создать/редактировать, требования, вопросы, условия, работодатель и стадии draft/open/paused/closed;
- [Кандидаты](./pages/candidates.html) — общий список откликов, поиск и фильтры по вакансии, агенту и статусу;
- [Карточка кандидата](./pages/candidate-detail.html?application=app-anna) — кандидат отдельно от откликов, сводка интервью, ручное изменение статуса и заметок HR.

**Связь с агентом:** вкладка «Вакансии» показывает назначенные позиции; «Настройки → Вакансии» позволяет выбирать из общего каталога (только у остановленного/чернового агента); «Кандидаты» показывает отклики, обработанные именно им. В «Подбор персонала» видны общие записи Workspace. Для иных профессий остаётся профильная вкладка «Заявки», без HR-навигации внутри агента.

**Данные:** `scripts/hr-data.js` предоставляет простой локальный демонстрационный store: вакансии, кандидаты и отдельные отклики. У компании есть две фиктивные вакансии и три фиктивных отклика, личный Workspace начинается пустым; сохранение в `localStorage` по ключу `aimock-hr-workspace-demo-v1` с разделением `company`/`personal`. Создание/изменение вакансии и ручная оценка кандидата сохраняются локально. Список назначений HR-агента хранится в прежних локальных настройках агента.

**Важные ограничения:** здесь нет реального сбора откликов, API, ATS/HRM интеграций, авторизации и серверных прав, загрузки/хранения резюме, автоматической отправки отказов или реального управления AI. В реальном продукте персональные данные требуют Workspace-level RBAC, аудита, согласий, политики хранения, разграничения доступа, а изменения вакансий у работающего агента — управляемых версий/публикации. Предпросмотр не является кадровой системой.

**Как проверить:** запустить `python3 -m http.server 8000`, открыть `http://localhost:8000/pages/vacancies.html`, создать вакансию, перейти в `pages/agent-detail.html?agent=a8&tab=settings` и открыть «Настройки → Вакансии» (агент — черновик), назначить вакансию; в действующем HR-агенте сначала нажать «Остановить». Затем открыть каталог кандидатов, фильтры и карточку отклика. Переключить Workspace с компании на личный, а тему — между тёмной и светлой.

## Переключение темы (изменения в draft PR #22)

- На всех **22 действующих HTML-страницах** добавлена доступная кнопка солнца/луны в верхней панели, включая локальный предпросмотр публичной карточки.
- По умолчанию остаётся утверждённая **тёмная тема**. Светлая тема — нейтральная бело-серая версия того же интерфейса с небольшими зелёными акцентами, без переделки структуры.
- Выбор сохраняется в `localStorage` (`aimock-theme-v1`) и применяется при навигации; если браузер запрещает доступ к хранилищу, переключение работает на текущей странице без сохранения.
- `scripts/theme.js` загружается в `head` до стилей, устанавливает `data-theme` на `html`, переключает значение и доступные названия/состояние кнопки.
- `styles/theme.css` содержит локальные overrides только для `html[data-theme="light"]` плюс оформление переключателя; исходные тёмные стили не изменялись.
- `archive/overview-light/` остаётся **историческим**, не частью актуальных страниц.
- Для воспроизводимой проверки сохранения темы между страницами предпочтительно открыть прототип через `python3 -m http.server 8000` и `http://localhost:8000/` (поведение `localStorage` на `file://` зависит от браузера).

Проверены структура, подключение темы на всех действующих страницах и синтаксис JS/CSS. Полноценный визуальный браузерный/E2E-прогон **не выполнялся**.

## Актуальный дизайн

**Тёмная минималистичная тема в духе ChatGPT, но со своей идентичностью AIMock.**

- [«Обзор» — открыть HTML](./index.html) — **утверждён, 26.10.2026**.
- [Базовые стили](./styles/overview-dark.css), [сетка и отступы](./styles/layout.css).
- [Демо-взаимодействия](./scripts/overview.js) — открытие меню и предпросмотров без выполнения реальных действий.
- [Правила визуальной системы](./docs/DESIGN_RULES.md).

Откройте `index.html` в браузере. Запуск сборки или сервера не требуется. Экран содержит только вымышленные демонстрационные данные. Доступны сворачивание меню, попап пространства и аккаунта, макетный поиск, предпросмотры списков и уведомлений. Нажатия на неразработанные разделы открывают честный экран-заглушку. Период меняет только подпись, показатели не пересчитываются.

### Структура

```text
index.html                         Главный эталон: Обзор (Dark)
styles/
  overview-dark.css                Стили актуального экрана
scripts/
  overview.js                       Только демо-взаимодействия (без API)
  overview-light.css               Стили архивного светлого варианта
archive/
  overview-light/
    index.html                     Историческая светлая версия
docs/
  DESIGN_RULES.md                  Зафиксированные дизайн-решения
```

### Статусы страниц

| Страница | Статус |
| --- | --- |
| Обзор организации | **Утверждён — текущий Dark Minimal** |
| Диалоги | Требует нового статического экранного эталона |
| Агенты: список | **Вариант 3 — доработка на согласовании**: стиль строк и аватаров унифицирован с «Обзором», таблица с компактными тегами и работающим popover, фильтры и пагинация без отдельного меню в конце строки |
| Детальная страница агента | **На согласовании** — профиль, обзор, вкладки, настройки и жизненный цикл |
| Workspace | Не утверждён |
| Команда (только организация-компания) | Не утверждена |
| Интеграции, Аналитика, Финансы и остальные | Не утверждены |

Ранее согласованные изображения могут служить вдохновением, но не считаются текущим дизайн-эталоном после перехода на новую тёмную тему.

### Правила изменений

Работаем **страница за страницей**, обновляем только согласованные элементы. Новый дизайн фиксируется в репозитории после просмотра и явного подтверждения. Стараемся придерживаться KISS/DRY, избегать дублирования общих компонентов и сложных декоративных конструкций.

**Важно:** этот репозиторий — источник визуальных решений. Актуальная продуктовая спецификация AIMock остаётся источником истины для функций, тарифов, интеграций и бизнес-правил.

- **Настройки агента v6 (на согласовании):** предметная задача, HR-вакансии и ответственный, уведомления, выбор модели, доступы/теги, ссылки на знания и интеграции. Глобальные профессиональные правила не редактируются.

- **Sharing & Copying v1.0 (визуальная проработка, не публикация):** верхние действия «Поделиться» и «Перенести», выбор материалов, предупреждение о повторном подключении, безопасный предпросмотр read-only карточки, серверные проверки прав/квот перед реальным копированием. Никаких настоящих share-токенов и экспортов в этом репозитории.

- **Редизайн детали агента:** компактный профиль, тёмно-фиолетовая локальная тема, обзор с показателями/задачей/событиями/динамикой; готовность к запуску перенесена в настройки, внутри настроек есть боковая навигация. Всё в ветке PR #14 до проверки.

- **Настройки готовой профессии (UI на согласовании):** HR/работодатель, вакансии, ответственный, необязательные пожелания; никаких обязательных универсальных промптов. [Открыть редактируемый черновик HR](./pages/agent-detail.html?agent=a8&tab=settings). Пример профиля работодателя и список загруженных материалов сохраняются только в браузере — это не API и не реальная загрузка.

## Деталка агента: карточки-разделы (редизайн 27.10.2026)

- `pages/agent-detail.html?agent=a1` — стартовый экран HR: **шесть кликабельных карточек**, без горизонтального меню: Настройки, Вакансии, Кандидаты, База знаний, Интеграции, Журнал. Тестирование доступно также из быстрых действий.
- При выборе карточки браузер **переходит по отдельному URL** `?agent=a1&tab=settings` и показывает полноэкранный **раздел** без профиля агента, без верхней панели вкладок и без обзорных карточек. «Вернуться к агенту» и крошки ведут назад. Все внутренние ссылки работают по тем же маршрутам; отдельный backend router не требуется для статического прототипа.
- `?agent=a1&tab=vacancies` — визуальный список вакансий; редактор вакансий потребует отдельной реализации. Для не-HR агента вместо «Вакансии» и «Кандидаты» показываются «Заявки» и «Тестирование», без доступа к HR-вакансиям.
- «Динамика работы» удалена из HTML и JS обзора. Остались четыре метрики (демоданные), «Последние события», «Основная задача», «Быстрые действия».
- Локальная палитра агентских экранов приближена к утверждённым «Обзору» и «Агентам» — графитовые поверхности, серые границы, приглушённый зелёный акцент. Глобальные страницы и каталог не изменялись.

Для оценки редактируемой версии: `pages/agent-detail.html?agent=a8&tab=settings`. Работающий агент доступен только для просмотра; остановка выполняется из начального экрана агента.

- **Настройки агента v2 (гибрид дизайнов №1 и №4):** сгруппированная боковая навигация, центральные формы и справа динамические подсказки по выбранному разделу. Проверка: [HR-агент](./pages/agent-detail.html?agent=a1&tab=settings), [редактируемый черновик](./pages/agent-detail.html?agent=a8&tab=settings), [менеджер заявок](./pages/agent-detail.html?agent=a2&tab=settings). Демонстрационные состояния и локальное автосохранение, без реального AI/API.

### Ветка для просмотра альтернативной деталки

`design/monochrome-agent-tabs-v1` — отдельный **не объединённый с main** вариант, где сохранено существующее меню AIMock, постоянный профиль агента и реальные разделы в горизонтальных вкладках без перезагрузки. Обновлённая **родная графитовая тема AIMock с умеренными зелёными акцентами** вынесена в `styles/agent-detail-refined.css`. Боковое меню и верхняя панель используют исходные утверждённые стили сайта без переопределения. Сценарии для просмотра локально: `pages/agent-detail.html?agent=a1` (HR), `?agent=a1&tab=settings` (настройки HR), `?agent=a8&tab=settings` (редактируемый HR-черновик), `?agent=a2` (менеджер заявок).


### Вариант №1 — компактная боковая карточка агента (на согласовании, 28.10.2026)
В этой ветке **заменена компоновка**: слева карточка конкретного агента (аватар, имя, состояние, описание, теги, профессия, пространство, режим модели и меню действий внизу), справа горизонтальные вкладки и одна рабочая область.
«Обзор» теперь состоит только из **Основной задачи** и **Ключевых показателей**; история операций остаётся во вкладке «Журнал».
Компоновка адаптивна: на узких экранах карточка профиля становится компактной верхней строкой. Настройки, HR-вакансии, интеграции, локальное автосохранение, ограничения активного агента и Sharing/Transfer не удалены. Ветка и PR #22 остаются draft, без merge в main.


### Палитра деталки (обновлено 28.10.2026)
Цвета **не подбираются отдельно**: новый вариант №1 использует базовые фон `#0e1011`, панели `#16191a`, KPI `#17191b` и нейтральные рамки из `styles/overview-dark.css`. Зелёный минимален — маленькая точка состояния и тонкое подчёркивание активной вкладки. Изменения только в `styles/agent-detail-refined.css` текущей ветки PR #22, `main` не затронут.
