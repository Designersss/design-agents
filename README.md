**Репозиторий визуальных эталонов AIMock.** Здесь находятся только утверждаемые HTML/CSS-макеты и правила интерфейса. Это **не приложение** и не реализация бизнес-функций.

## Как посмотреть

Откройте `index.html` в браузере. Сторонние зависимости, сборщик, сервер, регистрация или авторизация не требуются.

- Основной эталон: **светлая тема**, Minimal Calm + Profile First.
- Данные и суммы на экранах демонстрационные.
- Кнопки и пункты меню изображены исключительно для проверки внешнего вида. **Никакого JavaScript и никакой логики действий здесь нет.**
- Файл `styles/overview.css` содержит стили текущего эталона; при появлении новых экранов общие стили выносим постепенно, без дублирования.
- Решения и процесс работы: [docs/DESIGN_RULES.md](./docs/DESIGN_RULES.md).

## Границы проекта

**Разрешено:** статический HTML, CSS/SCSS, SVG, примерные состояния интерфейса, демонстрационные данные, адаптивная композиция и документация визуальных решений.

**Не добавлять:** обработку кликов/форм, SPA-логику, настоящую навигацию, сетевые запросы, API, SDK, аутентификацию, БД, тарифные расчёты, управление агентами, автоматизацию, реальные подключения или любую симуляцию бизнес-процессов.

Каждый новый экран сначала предлагается как дизайн, обсуждается и дорабатывается, затем фиксируется здесь как **approved**. Нельзя самостоятельно переносить неподтверждённые макеты в раздел утверждённых.

## Как использовать при разработке продукта

Этот репозиторий — **источник визуального соответствия** (компоновка, размеры, типографика, состояния). Источником функциональных требований остаётся актуальная продуктовая спецификация AIMock. Не переписывать продуктовую архитектуру, исходя из демонстрационных данных на этих экранах.
