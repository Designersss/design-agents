AI-рекрутер

Основная задача

Назначение

HR-рекрутер помогает проводить первичный отбор кандидатов на назначенные вакансии. Он опирается на подтверждённые требования каждой позиции и сведения работодателя.

Как работает

Принимает отклики, проводит первичное интервью, уточняет опыт и ожидания кандидатов. Проверяет полноту информации.

Результат работы

Готовит сводку для ответственного HR. Решения о приёме и окончательном отказе принимает только человек.

HR уже умеет проводить интервью — ему нужны вакансии с настоящими требованиями

Пример данных

Один агент может обрабатывать несколько вакансий, в том числе для разных работодателей. Требования, зарплата, вопросы, каналы и юридическая информация задаются в каждой вакансии отдельно.
