# Правила дизайна AIMock

Последнее обновление: **26 октября 2026**.

## 1. Направление
- **Minimal Calm + Profile First.** Максимально понятный UI, плотный, но не перегруженный, с узнаваемыми аватарами и аккуратными списками.
- Основная тема — **светлая**. Тёмные примеры служат только источником композиционных решений, не образцом цветовой схемы.
- Не добавлять приветствие «Добро пожаловать» на главную, пустые маркетинговые секции, крупные декоративные дашборды и искусственно раздутую статистику.
- Текущая главная: «Сейчас в AIMock» → команда/диалоги/действия/интеграции → события/AI-кошелёк.
- Рабочая область — на высоту экрана, без прокрутки всей страницы на целевом десктопном размере; адаптация под другие экраны — отдельный предмет приёмки.

## 3. Описание элементов
- Используем простые подписи на русском, не показываем пользователю технические идентификаторы, внутренние ключи, маршруты провайдера и закупочные цены.
- Отображаем реальные для релиза интеграции: **Telegram Bot API**, **amoCRM**, **Битрикс24**; другие сервисы не маркируем подключёнными.
- Для агента: аватар, имя, описание, статусы, теги, вкладки. Разделы и действия соответствуют актуальной спецификации.
- Для диалогов: удобный список, переписка, контекст, признаки передачи человеку; диалоги остаются в исходном канале.
- Статусы/суммы/проценты в макетах — только демо; не смешивать с настоящими системными ограничениями и тарифами.
- Не подменять продукт обычным AI-чатом; AIMock — рабочая платформа AI-сотрудников.

## 4. Порядок утверждения
1. Одна страница и её назначение.
2. Дизайн с демонстрационными данными, без функциональной логики.
3. Совместный разбор размеров, композиции, деталей, состояний и адаптивности.
4. Только после явного утверждения — обновление эталона и отметка **approved** в README.
5. Следующие страницы используют ранее утверждённые глобальные элементы; любые исключения обсуждаются отдельно.

**Обязательное правило:** эстетически похожая иллюстрация ≠ утверждённый кодовый эталон. Точное соответствие фиксируется только после просмотра статической страницы.
