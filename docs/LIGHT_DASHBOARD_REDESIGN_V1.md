# AIMock — Light Dashboard Redesign v1

**Статус:** дизайн-прототип для визуального согласования. **Не сливать в main до подтверждения.**

## Реализовано
- Новый светлый интерфейс главного экрана. Он изолирован от прежних тёмных CSS и JS.
- Карточный язык выбранной пользователем «Библиотеки агентов»: белые поверхности, пастельные круглые иконки, чёрные pill-кнопки, спокойная типографика.
- Рабочая общая страница **«Обзор»** с четырьмя демопоказателями, четырьмя карточками профессий, событиями «Требует внимания», последними событиями и подключениями.
- Общая боковая навигация; все разделы, кроме «Обзора», показывают «В разработке».
- В контексте конкретного агента sidebar заменяется меню агента с кнопкой «Все агенты»; содержимое разделов пока «В разработке».
- Поиск по разделам и демоагентам, Cmd/Ctrl+K, Esc, уведомления, мобильное меню, переключатель демопериода 7/30.
- На desktop внешний экран не прокручивается, прокрутка внутри workspace; адаптивность для узких экранов.

## Новая навигация
- #/overview — общая страница «Обзор».
- #/agents, #/library, #/messages, #/integrations и прочие — заглушки.
- #/agent/consultant/overview — переключение на меню агента; сам обзор агента заглушка.
- #/agent/recruiter/settings — настройки HR-агента, пока заглушка.

Новые страницы используют hash-маршруты в корневом HTML. Rewrite-сервер не нужен.

**Legacy:** старые файлы в pages/, styles/ и scripts/ сохранены без изменений для истории. В новой навигации ссылок на них нет, но прямое открытие legacy URL пока показывает старый UI. Их замена/архивирование — предмет следующих PR.

## Честные ограничения
Это статический дизайн-прототип без API, авторизации, настоящего AI, выполнения действий или биллинга. **Все** статусы, агенты, цифры и события вымышленные. Изменение периода просто переключает предопределённые демонстрационные цифры. Кнопка агента открывает заглушку, а не запускает агента.

## Локальная проверка
Запустить сервер:
- python3 -m http.server 8000
- Открыть http://localhost:8000/

Автоматические тесты без npm-зависимостей:
- node --check scripts/redesign-v1.js
- node --test tests/light-dashboard.test.mjs

Smoke-test:
1. Проверить общий обзор, карточки и адаптивность на 1440/1024/768/390 px.
2. Переключить 7/30 дней и проверить подписи.
3. Открыть «Агенты», «Библиотеку», «Сообщения» — должны быть заглушки.
4. Открыть карточку агента — sidebar становится контекстным.
5. Выбрать «Настройки» агента — заглушка внутри контекста. «Все агенты» возвращает глобальное меню.
6. Проверить поиск (Cmd/Ctrl+K, Esc), уведомления и меню на мобильном.

Тесты целостности кода не равны визуальному/E2E тестированию. Не считать CI пройденным до фактического результата.
